# v0.5.0 Native macOS Smoke Checklist

Run this checklist on a real Mac before publishing v0.5.0 as a stable release.

- [ ] Download the correct native package for the Mac architecture.
- [ ] Unzip `Codex Quota Dock.app`.
- [ ] Open the app and approve it in Privacy & Security if Gatekeeper blocks it.
- [ ] Confirm the menu bar icon appears.
- [ ] Open the floating monitor and drag it around the screen.
- [ ] Open Settings from the menu bar or monitor.
- [ ] Click `Import Current` and confirm a profile appears.
- [ ] Paste fixture or secondary auth JSON and create a new profile.
- [ ] Pin a profile and confirm it appears in the floating monitor.
- [ ] Refresh quota and confirm the UI does not freeze.
- [ ] Switch to a profile and confirm `~/.codex/auth.json` is replaced.
- [ ] Confirm a backup appears under `~/Library/Application Support/codex-quota-dock/backups`.
- [ ] Enable restart after switch and confirm Codex restart behavior.
- [ ] Quit from the menu bar.
