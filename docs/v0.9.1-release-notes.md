# Codex Quota Dock v0.9.1

## Highlights

- Restored quota monitoring for the latest Codex/ChatGPT usage payloads.
- Windows now refreshes expired access tokens and persists refreshed credentials back to the matching profile.
- Added `.codex/.env` proxy support on Windows and macOS for quota, token refresh, update checks, and downloads.
- Kept the Windows UI responsive by moving quota refresh work off the UI thread.

## Usage And Compatibility

- Correctly classifies 5-hour and weekly windows by duration across legacy and current API response shapes.
- Shows a clear `not reported` state when the service omits a quota window.
- Reads current Codex SQLite thread usage at a low frequency and includes it in local usage analysis.
- Handles UTF-8 BOM-prefixed auth JSON files.
- Improves Codex process detection and relaunch behavior for non-default installation paths.

## Desktop Experience

- Windows Auth JSON and other native edit controls now support `Ctrl+A` select-all.
- macOS keeps native `Command+A` behavior through SwiftUI's system text editor.
- Windows refresh failures now include actionable WinHTTP error codes.
- `NO_PROXY` IPv6 loopback entries are normalized for WinHTTP compatibility.

## Release Assets

- `codex-quota-dock-native-windows-amd64.exe`
- `codex-quota-dock-native-macos-universal.zip`
- `SHA256SUMS.txt`

## Notes

- macOS builds are unsigned. If Gatekeeper blocks the app, approve it in System Settings > Privacy & Security, or build locally from source.
- Profile auth files remain local files and are never included in release artifacts.
