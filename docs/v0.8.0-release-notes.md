# Codex Quota Dock v0.8.0

This release focuses on native macOS parity with the Windows monitor workflow and keeps the native Windows build in the release lane.

## Highlights

- macOS monitor rows can now be selected directly, and Switch uses the selected profile.
- macOS monitor selection state now updates correctly after choosing another profile.
- macOS local usage analysis now reads Codex SQLite state and database files in addition to JSONL logs.
- macOS profile switch can restart Codex automatically after switching, with a more reliable quit-and-reopen sequence.
- macOS settings now tolerate unknown legacy auto-switch mode values instead of discarding the full settings file.
- Windows native auto-switch changes from `dev` are included in the release build.
- Tag pushes now build both native desktop packages and publish the GitHub Release automatically.

## Downloads

- `codex-quota-dock-native-macos-universal.zip`

## macOS Note

The macOS app is ad-hoc signed but not Apple-notarized. If macOS blocks the app, open `System Settings` -> `Privacy & Security` and choose `Open Anyway`.
