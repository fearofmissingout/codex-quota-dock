# v0.3.2 Release Notes

This patch release focuses on Windows auth switching reliability and makes saved auth JSON editing easier to discover.

## Highlights

- Added an automatic Codex restart option after switching auth.
- Fixed Windows packaged-app restart behavior by launching Codex through its Start menu AppID instead of directly relying on the WindowsApps executable.
- Windows restart now waits for the old packaged Codex process tree to exit, retries activation, and verifies that a new Codex desktop process appears.
- Avoids `taskkill /T` so Codex Quota Dock does not terminate itself when it was launched from a Codex child process.
- Added inline `Save Auth JSON` and `Reload JSON` controls directly inside the `Auth JSON` editor tab.
- Added a project TODO for the proposed native macOS SwiftUI/AppKit edition.

## Notes

- Automatic restart does not require administrator privileges when Codex and Codex Quota Dock run as the same user.
- Existing Codex windows may lose unsaved input when automatic restart is enabled, so the switch confirmation dialog warns before closing Codex.
- Stored auth/profile data remains local and uses the existing app data format.
