# v0.3.0 Release Notes

These notes summarize the v0.3 release.

## Highlights

- Added separate 5h and weekly low-quota alerts for monitored profiles.
- Added lower-size release builds with stripped metadata.
- Added safer release builds that disable Go VCS stamping.
- Improved Windows local build scripts so failed builds do not report success.
- Improved CI so only the newest branch build remains active.
- Changed macOS amd64 artifact generation to avoid long Intel runner queues.

## Low-Quota Alerts

- Configure 5h and weekly alerts separately as `Off`, `5%`, `10%`, `15%`, `20%`, `30%`, or `40%`.
- The default alert threshold is `10%` for 5h quota and `30%` for weekly quota.
- Alerts are evaluated after a successful quota refresh.
- Alerts escalate from warning to critical at `5%`, then exhausted at `0%`.
- If both 5h and weekly quota need attention for one profile during the same refresh, the app combines them into one system notification.
- Duplicate notifications are suppressed until quota recovers above the threshold; severity upgrades can still notify you.

## Build and Artifact Changes

- Release builds use `-buildvcs=false`, `-trimpath`, and stripped linker flags.
- Windows GUI builds continue to use `-H=windowsgui`, so the app opens without a terminal window.
- Windows local scripts now resolve `gcc` and pass its location through `CC` and `COMPILER_PATH` for more reliable CGO builds.
- PowerShell local builds now fail immediately if `go test`, `go build`, or `strip` fails.
