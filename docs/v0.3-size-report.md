# v0.3 Size Report

This report records the local Windows build-size comparison for the v0.3 preview.
It intentionally avoids auth file names, account names, tokens, and local user-specific config values.

## Summary

The v0.3 preview is materially smaller than v0.2.0 after enabling stripped release builds.

| Artifact | v0.2.0 | v0.3 preview | Change |
| --- | ---: | ---: | ---: |
| Windows exe | 50.84 MB | 24.46 MB | -51.9% |
| Windows zip | 17.77 MB | 11.43 MB | -35.7% |

## What Changed

- GitHub Actions release builds use `go build -trimpath -ldflags="-s -w"` on all platforms.
- Windows release builds also use `-H=windowsgui` to avoid opening a terminal window.
- Local build scripts run a no-CGO test preflight first, then build the GUI app with CGO enabled.
- Local build scripts run `strip --strip-all` when the tool is available.
- Local scripts no longer force a repo-local `.gocache`, which avoids repeated cold CGO rebuilds.

## Why It Is Still Not Tiny

Codex Quota Dock uses Go, Fyne, CGO, and OpenGL-related desktop dependencies. The distributed executable is largely self-contained, so it includes the Go runtime and GUI/rendering dependencies. This is expected for the current cross-platform desktop approach.

## Further Options

- Keep the current stripped Go/Fyne release build as the default. This is the safest option for v0.3.
- Consider optional UPX-compressed artifacts only if users explicitly want smaller downloads. UPX can trigger antivirus false positives and should not replace the normal release asset.
- A separate native Windows implementation could be smaller, but it would split the codebase and reduce cross-platform consistency.
