# v0.4.0 Release Notes

This release focuses on making Codex Quota Dock feel like a polished desktop utility: safer profile migration, update checks, startup controls, a real app icon, and a quota bar bug fix.

## Highlights

- Added a flat Codex Quota Dock icon for the app, taskbar, tray, and macOS bundle packaging.
- Fixed quota progress bars sometimes staying visually full after the remaining percentage dropped.
- `Import Current` and `Import File` now open a naming/confirmation dialog instead of requiring the alias field to be pre-filled.
- Added `New Profile` for creating a saved profile by pasting auth JSON.
- Added full backup export/import for moving profiles and settings to another machine.
- Added `Restore Backup` for rolling back to the latest active auth backup.
- First launch with no saved profiles now opens Settings automatically.
- Added `Start at login` support on Windows, macOS, and Linux.
- Added GitHub Releases update checks with user-confirmed download/install.
- Added an `Updates` tab and a `Health` tab in Settings.
- Release builds now inject the app version into the binary for update comparison.

## Safety Notes

- Exported backup files contain complete auth credentials. Keep them private and never commit them to GitHub.
- Update checks only check and notify by default. The app does not install updates unless the user confirms.
- Switching auth still creates a timestamped backup before replacing the active Codex auth file.
