# v0.5.0 Release Notes

This preview starts the native macOS rewrite while keeping the Go/Fyne app available for Windows, Linux, and fallback macOS usage.

## Highlights

- Added a Swift/AppKit native macOS preview app under `native/macos/CodexQuotaDock`.
- Added native macOS menu bar entry, translucent floating monitor, and basic settings window.
- Reused the existing local profile storage under `~/Library/Application Support/codex-quota-dock`.
- Added native core support for profile metadata, saved auth JSON, auth switching with backup, quota parsing, health rows, and Codex restart requests.
- Added shared contract fixtures so Go and Swift agree on `profiles.json`.
- Added native macOS GitHub Actions build jobs for Apple Silicon and Intel artifacts.

## Preview Limitations

- The native app is a preview and does not yet include local usage charts.
- Native automatic update installation is not included yet.
- macOS builds are ad-hoc signed but not notarized. Users may need to approve the app in Privacy & Security.

## Artifacts

- `codex-quota-dock-native-macos-arm64.zip`
- `codex-quota-dock-native-macos-x86_64.zip`
- Existing Go/Fyne artifacts remain available for all supported platforms.
