# Codex Quota Dock v0.7.0

This release moves Codex Quota Dock to native desktop builds only and ships a universal macOS package.

## Highlights

- macOS native app now uses a Windows-native-aligned monitor and settings experience.
- macOS Settings now has Auth, Quota, Usage, Settings, Health, and Updates tabs.
- macOS Touch Bar support shows active profile quota and provides Refresh/Switch actions.
- Added profile priority and conservative auto-switch policy controls.
- Added local usage analysis for the macOS native app.
- Windows native build version is now `0.7.0`.
- macOS is now published as one universal package for Apple Silicon and Intel Macs.
- New releases no longer publish the old Go/Fyne Windows, macOS, or Linux packages.

## Downloads

- `codex-quota-dock-native-windows-amd64.zip`
- `codex-quota-dock-native-macos-universal.zip`

## macOS Note

The macOS app is ad-hoc signed but not Apple-notarized. If macOS blocks the app, open `System Settings` -> `Privacy & Security` and choose `Open Anyway`.
