# v0.6.0 Native Windows Preview

This preview introduces a Windows 11-only native C++/Win32 app while keeping the Go/Fyne build as the stable fallback.

## Scope

- Reads and writes the existing `%APPDATA%\codex-quota-dock` profile store.
- Imports, edits, pins, deletes, backs up, restores, and switches auth profiles.
- Shows a compact floating monitor with current and pinned profiles.
- Fetches 5h and weekly quota through the existing ChatGPT usage endpoint.
- Supports 1, 5, and 10 minute polling.
- Supports startup registration, health checks, update checks, local usage summary, and best-effort Codex restart.

## Build

```powershell
.\scripts\build-windows-native.ps1
```

GitHub Actions uploads `codex-quota-dock-native-windows-amd64.zip`.

## Notes

- Windows 10 is intentionally unsupported for the native preview.
- The first native Windows UI uses Win32 controls and GDI for a small dependency-free executable.
- The Go/Fyne Windows artifact remains available until the native preview reaches parity in real use.
