# v0.3.1 Release Notes

This patch release improves the macOS download experience without requiring a paid Apple Developer ID certificate.

## Highlights

- macOS artifacts are now packaged as `Codex Quota Dock.app` bundles instead of bare executables.
- macOS app bundles are ad-hoc signed with `codesign --sign -`.
- README now explains how to open the unsigned app from `System Settings -> Privacy & Security`.
- README now calls out Apple Silicon (`arm64`) and Intel (`amd64`) package selection.

## macOS Gatekeeper

The macOS app is not Apple-notarized. If macOS says Apple cannot verify the app, open `System Settings -> Privacy & Security`, choose `Open Anyway`, then confirm `Open`.

This warning is expected for unsigned public builds and does not mean macOS found malware. A fully notarized release still requires a paid Apple Developer ID certificate.
