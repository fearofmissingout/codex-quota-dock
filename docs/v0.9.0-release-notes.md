# Codex Quota Dock v0.9.0

## Highlights

- Added real in-app update checks for native Windows and macOS builds.
- Added SHA256 verification for downloaded release assets.
- Added Windows automatic install and restart for verified `.exe` updates.
- Added macOS in-app download, verification, install-and-restart flow for universal `.app` zips.
- Added macOS Privacy & Security guidance for unsigned builds.

## Usage

- Local usage charts now show effective usage by excluding cached input.
- 5h and weekly reset times now include month/day and time, such as `07/03 18:30`.
- Token mix now separates uncached input, cached input, output, and SQLite totals more clearly.

## Release Assets

- Windows releases now include both:
  - `codex-quota-dock-native-windows-amd64.exe`
  - `codex-quota-dock-native-windows-amd64.zip`
- macOS releases continue to include:
  - `codex-quota-dock-native-macos-universal.zip`
- Releases now include:
  - `SHA256SUMS.txt`

## Notes

- Windows automatic update uses the `.exe` asset and preserves startup settings because the app replaces itself in place.
- macOS cannot approve an unsigned app before it starts. If Gatekeeper blocks the app, approve it in System Settings > Privacy & Security, or build locally from source.
