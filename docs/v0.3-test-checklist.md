# v0.3 Test Checklist

Use this checklist before publishing v0.3. It avoids account names, auth file contents, tokens, and local private paths.

## Launch

- Start the Windows preview executable.
- Confirm the compact floating monitor opens without a terminal window.
- Confirm the window is borderless, draggable, and remains usable after moving it across the screen.
- Double-click the floating monitor and confirm the detail/config window opens.

## Profiles

- Confirm all configured profiles appear in the floating monitor.
- Confirm the current profile and pinned profiles show separate `5h` and `weekly` quota lines.
- Switch profiles from the floating monitor.
- Confirm the app replaces the active Codex auth file and shows the restart-Codex prompt.
- Confirm the restart prompt can be disabled in configuration.

## Configuration

- Add a new profile with an alias and auth JSON content.
- Edit the alias of an existing profile.
- Edit the auth JSON content of an existing profile.
- Delete a profile and confirm it disappears from the monitor and details view.
- Change polling between `1 minute`, `5 minutes`, and `10 minutes`.
- Use manual refresh and confirm quota values update.

## Alerts

- Confirm the low-quota alert setting shows `Off`, `5%`, `10%`, `20%`, and `30%`.
- Set a threshold and refresh a profile that is below the threshold.
- Confirm the app sends one system notification per low quota window.
- Refresh again while still below the threshold and confirm it does not spam duplicate notifications.

## Usage View

- Open the usage view.
- Confirm per-profile usage is distinguishable.
- Confirm daily usage and overall usage charts are readable without clipping.
- Resize or reopen the details window and confirm the layout remains readable.

## Build Size

- Confirm the v0.3 Windows artifact is about `24.38 MB` after extraction.
- Confirm the v0.3 Windows zip is about `11.57 MB`.
- Compare against v0.2.0 Windows exe at about `50.84 MB`.
- Confirm the size report records the reduction and the CI artifact source.

## Safety

- Confirm no real auth JSON, token, account alias, or machine-specific private path appears in committed files.
- Confirm switching creates or preserves a backup before replacing the active auth file.
- Confirm Codex itself still requires a restart after switching auth.
